How to host on GitHub Pages





Create a new GitHub repository (recommended name: keepmemo)



Upload all files from this folder to the root of the repository



Go to Settings → Pages



Under Source, choose Deploy from a branch



Select branch main and folder / (root)



Save

Your site will be live at: https://cleversta.github.io/keepmemo/

(If your GitHub username is different, adjust accordingly.)

Before publishing

Replace the Google Play link in index.html with your real Play Store URL when the app is published:

https://play.google.com/store/apps/details?id=YOUR_PACKAGE_NAME
